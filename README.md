# goit-rdb-hw-04

Домашнє завдання №4 з реляційних баз даних.

У цій роботі я працювала з датасетом Olist Brazilian E-Commerce з Kaggle. Дані завантажувала в Google Colab за допомогою kagglehub та працювала з ними в PostgreSQL.

Під час виконання завдання я створила raw та typed таблиці, виконала DML-запити та зробила сегментацію покупців. Також працювала з різними видами JOIN, GROUP BY, HAVING, STRING_AGG, INTERSECT та ROW_NUMBER().

Для роботи використовувала таблиці customers, orders, order_items, products, sellers та order_reviews.

Основні таблиці датасету:
- customers - 99 441 рядок
- orders - 99 441 рядок
- order_items - 112 650 рядків
- products - 32 951 рядків
- sellers - 3 095 рядків
- order_reviews - 99 224 рядки
